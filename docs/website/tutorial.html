Tutorial: a coin game

Build a small game from an empty place in about 15 minutes. Coins lie around the map, players walk into them, the server checks every pickup, and each player's coins are saved.

1. Set up the place

  1. Create a new Baseplate place in Studio.
  2. Install the Branch Studio plugin. On its Overview page, press Install (this puts Branch in ReplicatedStorage.Packages) and switch on Compiled networking.
  3. Make the folders and start Branch on both sides:

2. Save each player's coins

Add a ModuleScript PlayerService to Services. Any module whose name ends with Service is started by Branch. Branch Studio fills the new module with a template; replace it with this:

Services/PlayerService 
local RunService = game:GetService("RunService")
local Branch = require(game.ReplicatedStorage.Packages.Branch)

local PlayerService = {}

function PlayerService:Init()
	Branch.Data.Server.Start({
		Template = { coins = 0 },
		Mock = RunService:IsStudio(), -- nothing is saved while you test in Studio
		Leaderstats = { coins = "Coins" }, -- shown on the player list
	})
end

return PlayerService
  • Template is what a new player starts with. Every later write is checked against it, so coins can never become a string or nil.
  • Mock keeps Studio tests from touching real saves.
  • Leaderstats shows coins on the player list and keeps it up to date.

Check: press Play. The player list shows Coins 0.

3. Put coins on the map

Add a second service, CoinService. Start with the part that places the coins:

Services/CoinService 
local Branch = require(game.ReplicatedStorage.Packages.Branch)

local CoinService = { Dependencies = { "PlayerService" } }

local coins: { [number]: BasePart } = {} -- coin id -> its part
local nextId = 0
local folder: Folder

local function spawnCoin()
	nextId = nextId % 65535 + 1
	local coin = Instance.new("Part")
	coin.Name = "Coin"
	coin.Shape = Enum.PartType.Cylinder
	coin.Size = Vector3.new(0.4, 3, 3)
	coin.Color = Color3.fromRGB(255, 200, 40)
	coin.Material = Enum.Material.Neon
	coin.Anchored = true
	coin.CanCollide = false
	coin.CFrame = CFrame.new(math.random(-40, 40), 2.5, math.random(-40, 40)) * CFrame.Angles(0, 0, math.rad(90))
	coin:SetAttribute("CoinId", nextId)
	coin.Parent = folder
	coins[nextId] = coin
end

function CoinService:Init()
	folder = Instance.new("Folder")
	folder.Name = "Coins"
	folder.Parent = workspace
	for _ = 1, 20 do
		spawnCoin()
	end
end

return CoinService
  • Dependencies makes PlayerService:Init run first, so player data is ready before any coin can be taken.
  • Init runs once, before anything starts: a good place to build the map. Every coin gets an id, so the server and the players can talk about "coin #7".

Check: press Play. 20 gold coins lie around the map (you cannot pick them up yet).

4. Let players collect coins

Picking up a coin has to go through the server: if a player's own script could add coins, an exploiter could add a million. Declare two events in CoinService, right below the first line local CoinService = ...:

CoinService.Network = {
	Collect = { From = "Client", Rate = "10/s", Data = "u16" }, -- a player asks to take coin #id
	Collected = { From = "Server", Data = "u16" }, -- tells everyone coin #id is gone
}

When you stop typing, Branch Studio compiles them into Branch.Network: autocomplete now knows Collect and Collected. Then add the server's side, at the end of CoinService before return:

function CoinService:Start()
	local Net = Branch.Network.Server.CoinService
	local Data = Branch.Data.Server

	Net.Collect.On(function(player, id)
		-- the server decides: the coin must exist and the player must be next to it
		local coin = coins[id]
		local character = player.Character
		local root = character and character:FindFirstChild("HumanoidRootPart")
		if not coin or not root or not Data.IsLoaded(player) then
			return
		end
		if (root.Position - coin.Position).Magnitude > 12 then
			return -- too far away: a real touch cannot do that
		end

		coins[id] = nil
		coin:Destroy()
		Data.Increment(player, "coins")
		Net.Collected.FireAll(id)
		task.delay(3, spawnCoin) -- a new coin somewhere else
	end)
end
  • Data = "u16": the coin id travels as a 2-byte number. The server refuses anything else before your code sees it.
  • Rate = "10/s": a player can ask at most 10 times a second; the rest are dropped.
  • The server checks the rest: the coin exists and the player stands next to it. A cheater asking for a far-away coin gets nothing.
  • Data.Increment adds the coin to the saved data, and the player list updates by itself.

5. Ask for a coin on touch

Now the players' side. Add a ModuleScript CoinController to Controllers (modules ending with Controller run on the client):

Controllers/CoinController 
local Players = game:GetService("Players")
local Branch = require(game.ReplicatedStorage.Packages.Branch)

local CoinController = {}

function CoinController:Start()
	local Net = Branch.Network.Client.CoinService
	local player = Players.LocalPlayer
	local asked: { [number]: boolean } = {} -- coins we already asked for

	local function watch(coin: BasePart)
		coin.Touched:Connect(function(hit)
			local id = coin:GetAttribute("CoinId")
			local character = player.Character
			if id and not asked[id] and character and hit:IsDescendantOf(character) then
				asked[id] = true
				Net.Collect.Fire(id) -- the server checks it and gives the coin
			end
		end)
	end

	local folder = workspace:WaitForChild("Coins")
	for _, coin in folder:GetChildren() do
		watch(coin :: BasePart)
	end
	folder.ChildAdded:Connect(watch)

	Net.Collected.On(function(id)
		asked[id] = nil -- ids are reused later
	end)
end

return CoinController

The client only asks: Net.Collect.Fire(id). The coin disappears for everyone when the server destroys it, and Collected tells every client that the id is free again.

6. Show the count

Last, a counter at the top of the screen. Branch.Data.Client is a read-only copy of the player's own data, kept in sync by the server:

Controllers/HudController 
local Players = game:GetService("Players")
local Branch = require(game.ReplicatedStorage.Packages.Branch)

local HudController = {}

function HudController:Start()
	local gui = Instance.new("ScreenGui")
	gui.Name = "Hud"
	gui.ResetOnSpawn = false

	local label = Instance.new("TextLabel")
	label.AnchorPoint = Vector2.new(0.5, 0)
	label.Position = UDim2.new(0.5, 0, 0, 16)
	label.Size = UDim2.fromOffset(220, 48)
	label.BackgroundColor3 = Color3.fromRGB(20, 22, 34)
	label.BackgroundTransparency = 0.2
	label.TextColor3 = Color3.fromRGB(255, 210, 70)
	label.Font = Enum.Font.GothamBold
	label.TextSize = 26
	label.Text = "Coins: 0"
	label.Parent = gui
	Instance.new("UICorner", label)

	gui.Parent = Players.LocalPlayer:WaitForChild("PlayerGui")

	-- runs now and after every change the server makes
	Branch.Data.Client.Observe("coins", function(coins)
		label.Text = `Coins: {coins}`
	end)
end

return HudController

Check: press Play and walk into the coins. The counter and the player list go up, and a new coin appears 3 seconds after each pickup.

7. What you built

  • Segments started in the right order, with no wiring: Segments.
  • Saved data that cannot be corrupted by a wrong write: Player data.
  • Networking that is typed, checked on the server and rate-limited: Networking.

Something does not work? Look up the message on Common errors, or compare with the finished place.

8. Ideas to try next

  • A sound for nearby players: add Pickup = { From = "Server", Data = "vector" } and send it with Net.Pickup.FireNear(coin.Position, 60, coin.Position). FireNear
  • Catch cheaters: log players whose packets are refused with Branch.Network.OnReject.
  • A best score: add best = 0 to the template and update it with Data.Update. Old saves get the new field by themselves.
