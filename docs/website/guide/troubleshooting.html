guide/troubleshooting

Common errors

Every message Branch prints, what it means and how to fix it. Search this page with Ctrl+F for a few words of your message, or search the whole site with Ctrl+K.

Red lines are errors in the Output; yellow ones are warnings. Messages that start with [Branch] come from the loader, which reports the problem and goes on starting everything else.

A segment does not start

My service or controller never runs

No message at all usually means Branch never saw the module as a segment.

  • Check the name. With the default rule, only modules whose name ends with Service (server) or Controller (client) are segments. ShopManager is a helper, not a segment. Branch Studio warns about it: ShopManager has Init/Start but is not loaded.
  • Check where it is. It must be under a folder you pass to Branch:Start (usually ServerScriptService.Services and StarterPlayerScripts.Controllers).
  • Check that Branch starts. A Script must call Branch:Start(...) on the server, and a LocalScript on the client. See Getting started.

… failed to load: …

[Branch] ServerScriptService.Services.ShopService failed to load: <the real error>

The module errored while it was being required, before Init. The rest of the line is the real error. Fix that error; the segment is skipped until then.

… must return a table

[Branch] ServerScriptService.Services.ShopService must return a table (got nil); skipped

A segment is a table of functions. End the module with return ShopService.

…:Init failed

[Branch] ShopService:Init failed: <the real error>

Its Init errored, so it is marked Failed: it does not start and its hooks are not connected. Segments that depend on it still start, with a warning: CoinService depends on ShopService, whose Init failed. Fix the first error; the others usually go away with it.

… is still running after 5 s

[Branch] ShopService:Init is still running after 5 s; every segment after it is waiting (a WaitForChild or DataStore call that never returns?)

Init runs one segment at a time, so a slow one holds up everything after it. Look for a WaitForChild on something that never appears, or a web or DataStore call. Move waiting into Start, which runs in its own thread.

segment "…" not found

Branch: segment "PlayerService" not found (phase Loading). Look segments up in :Init() or later, not at module top level.

GetSegment was called while modules were still loading, or with a name that is not a segment. Move the call into Init or Start, and check the spelling.

dependency cycle / depends on …

[Branch] dependency cycle: ShopService -> CoinService -> ShopService

Two segments list each other in Dependencies, so neither can Init first. Remove one of the two: usually one only needs the other in Start, which always runs after every Init. A name in Dependencies that is not a segment is reported too: ShopService depends on "CoinServce", which is not a segment.

two segments are named …

[Branch] two segments are named "ShopService": ServerScriptService.Services.ShopService and ServerScriptService.Services.Old.ShopService; the second was skipped

Segment names must be unique on each side; the second one is skipped. Rename or delete one.

…:Heartbeat errored

[Branch] ShopService:Heartbeat errored: <the real error>

A hook errored. The other segments' hooks keep running, and the message repeats at most once every 5 seconds. Fix the error in that hook.

Branch.… does not exist

Branch.Netwrok does not exist

A typo on Branch. The fields are Network and Data; utilities are modules: require(Packages.Branch.Util.Timer).

Branch:Start can only be called once

Branch:Start can only be called once

Two scripts start Branch on the same side. Keep one, and pass every root folder to it: Branch:Start(folderA, folderB).

Player data

… before their data loaded

Branch.Data: Set for Player1 before their data loaded; use Data.Await(player) or Data.OnLoaded

Data loads a moment after a player joins. Write in Data.OnLoaded(function(player, data) ... end), or call Data.Await(player) first. Reads before that return nil.

"…" holds a … in the template, got …

Branch.Data: "stats.kills" holds a number in the template, got string

Every write is checked against your template. Write the type the template has, or change the template (and add a migration for saves that already exist). Related: "…" is missing (the template has it) when a table you set lacks a key, and "…" is part of the template and cannot be set to nil.

"…" cannot hold nan (DataStores cannot save NaN or infinity)

Branch.Data: "ratio" cannot hold nan (DataStores cannot save NaN or infinity)

Usually a division by zero, such as kills / deaths with 0 deaths. One NaN would make every later save of that profile fail, so it is refused here. Guard the division: if deaths > 0 then ... end.

cannot Increment "…"

Branch.Data: cannot Increment "stats" (table)

Increment only works on numbers. Point it at a number: "stats.kills", not "stats".

the client is still waiting for its data after 15 s

[Branch.Data] the client is still waiting for its data after 15 s; is Branch.Data.Server.Start called on the server?

A client uses Branch.Data.Client, but the server never started data. Call Branch.Data.Server.Start({...}) in a service's Init.

My data is not saved in Studio

[ProfileStore]: Roblox API services unavailable - data will not be saved

Studio has no DataStore access for this place. Either pass Mock = RunService:IsStudio() to Data.Start (nothing is saved while testing, on purpose), or publish the place and turn on Game Settings → Security → Enable Studio Access to API Services.

Networking

Branch.Network is not compiled

Branch.Network is not compiled: turn on Network in Branch Studio and declare Service.Network tables

Branch.Network is written by the Branch Studio plugin. Install Branch Studio, turn on Compiled networking on its Overview page, and declare a Network table in a service.

Branch.Network.Server is only available on the server

Branch.Network.Server is only available on the server

A LocalScript or controller used Branch.Network.Server. Use Branch.Network.Client on the client, and Server in services. The same goes the other way round, and for OnReject (server only).

My event is not in Branch.Network

  • Is it declared in a service? Only server segments declare Network. A controller that declares one gets the problem only server segments (services) declare Network.
  • Is the service under a root Branch Studio reads? See Settings → Paths.
  • Does the declaration have a problem? Open Branch Studio's Overview page: while a declaration has an error, the last working Branch.Network stays, without your new event.

… expected …, got …

Branch.Network: Combat.Damage.Fire #1 expected u8, got number (300)

An argument does not match the declaration: here, 300 does not fit in a u8. Send what the declaration says, or change the type. These checks run in Studio; the rest of the frame is sent normally.

… failed on the server

Branch.Network: Shop.Buy failed on the server

Invoke errors on the client when the server could not answer: the handler errored (the server's Output has Shop.Buy handler errored: …), it returned values that do not match Return, it went over its Rate, or no handler was set before the queue filled up. Look at the server's Output for the reason, and wrap the call in pcall where a failure is possible.

rejected a packet from …

Branch.Network rejected a packet from Player1: <reason>

A client sent data that does not match the declarations: a wrong size, a value out of range, a NaN, a wrong Instance class. The packet was dropped. From a normal client this does not happen, so it is usually an exploiter: handle it in Branch.Network.OnReject. A reason starting with rate limit: means the client went over the event's Rate.

A listener never gets called

  • Is it connected on the right side? A From = "Client" event is heard with .On on the server, and the other way round.
  • Is it Latest, Hz or Lod? Those send at the end of the frame, and Lod's FireFrom skips players beyond the last ring and players without a character.
  • Is it Unreliable? Unreliable events can be lost, especially in the first seconds after a player joins.

Branch Studio

… has Init/Start but is not loaded

ShopManager has Init/Start but is not loaded: segment names end with Service (Settings > Segment rule)

See My service or controller never runs. Rename it to end with Service or Controller, or switch the segment rule to Folders.

Enum(…) is not an Enum / Instance(…) is not a known class

Combat.Hit: Enum(KeyCodes) is not an Enum

A typo in an engine name inside a type. Fix the spelling: Enum(KeyCode), Instance(Model). A wrong Enum stops the network from compiling; an unknown class compiles, but the server would refuse every packet.

unknown option "…" (did you mean …?)

Combat.Hit: unknown option "Tpye" (did you mean "Type"?)

A typo in an event option. The full list is in Networking → Options. Other declaration errors (such as Delta needs a Reliable event) say what to change in the same way.

Data template changed

Data template changed: removed "stats.best". Saved player data keeps the old shape, so add a migration …

Saved data does not follow a template change on its own. Write a migration, then click the warning to accept the new shape.

Nothing compiles when I type

  • Is Live on? The Live button on the Branch toolbar turns compiling as you type on and off; Compile compiles now.
  • Is the runtime installed? The Overview page shows it; press Install or Update.
  • Is Studio in Play? The plugin does not compile during Play.
