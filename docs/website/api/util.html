Utilities

Three small modules ship inside the package. They are ModuleScripts, not fields of Branch, so require them directly:

local Util = game.ReplicatedStorage.Packages.Branch.Util
local Scythe = require(Util.Scythe)
local ThreadReaper = require(Util.ThreadReaper)
local Timer = require(Util.Timer)

Scythe

Cleanup without objects. A scope is a plain number handle. You add things to it, and cleaning the scope disposes all of them, newest first. Unlike Maid or Trove there are no objects or metatables, so creating a scope costs almost nothing.

local scope = Scythe.scope()
Scythe.add(scope, workspace.Part)                  -- :Destroy()
Scythe.add(scope, humanoid.Died:Connect(onDied))   -- :Disconnect()
Scythe.add(scope, task.spawn(loop))                -- task.cancel()
Scythe.add(scope, function() print("bye") end)     -- called

Scythe.clean(scope)    -- dispose everything; the scope stays usable
Scythe.destroy(scope)  -- dispose everything and retire the handle

Scythe.scope

Scythe.scope(): Scope

A new, empty scope.

Scythe.add

Scythe.add<T>(scope: Scope, value: T): T

Tracks value and returns it, so you can wrap creation: local part = Scythe.add(scope, Instance.new("Part")). Errors if the value has no way to be cleaned up.

Scythe.addBulk

Scythe.addBulk(scope: Scope, ...: unknown)

Tracks several values in one call. All or nothing: if any value cannot be cleaned up, none are added. nil in the list is an error.

Scythe.remove

Scythe.remove(scope: Scope, value: unknown): boolean

Stops tracking value without disposing it, for when something else takes ownership. Returns whether it was found.

Scythe.clean

Scythe.clean(scope: Scope)

Disposes everything, newest first, and keeps the scope ready for reuse. Every item is disposed even if some disposers error; the errors are raised together afterwards.

Scythe.destroy

Scythe.destroy(scope: Scope)

Cleans the scope and retires its handle. Using the handle afterwards is an error, never a silent mix-up with a newer scope.

Scythe.count

Scythe.count(scope: Scope): number

How many items the scope tracks.

Scythe.isAlive

Scythe.isAlive(scope: Scope): boolean

Whether the handle points to a live scope.

Disposers must not yield. A disposer may add to, remove from, clean or destroy its own scope, but a yield would leave the scope half-cleaned for other threads.

ThreadReaper

Like task.spawn, task.defer and task.delay, but threads are reused from a pool, so spawning often costs less.

ThreadReaper.Spawn

ThreadReaper.Spawn(callback: (...A) -> (), ...: A)

Runs callback now, in a pooled thread.

ThreadReaper.Defer

ThreadReaper.Defer(callback: (...A) -> (), ...: A)

Runs callback at the next resumption point, like task.defer.

ThreadReaper.Delay

ThreadReaper.Delay(duration: number, callback: (...A) -> (), ...: A): number

Runs callback after duration seconds and returns a token for Cancel. A negative duration means "now"; NaN is an error. ThreadReaper.Timeout is the same function.

ThreadReaper.Cancel

ThreadReaper.Cancel(token: number): boolean

Cancels a pending Delay. Returns whether it was still pending.

ThreadReaper.Reserve

ThreadReaper.Reserve(count: number)

Pre-creates up to count threads in the pool, so a later burst does not create them on the spot.

Timer

Countdown timers that you can pause, resume, extend and wait on. Branch 2 fixes the Branch 1 bugs:

  • a pause no longer counts as elapsed time;
  • extending a timer keeps the queue in order;
  • Stop wakes waiting threads;
  • callbacks never run twice, and one that errors cannot break other timers.
local round = Timer.new(90)          -- 90 seconds, not running yet
round:OnFinished(function() print("time!") end)
round:Start()

task.wait(10)
round:Pause()
round:IncrementTime(15)              -- +15 seconds
round:Resume()
local state, elapsed = round:Wait()  -- yields until it finishes or stops

Timer.new

Timer.new(length: number): Timer

A timer of length seconds. It starts Paused: call Start (or Resume) to run it. Errors if length is not a number.

timer:Start

timer:Start() -- alias: Play

Starts, or restarts, from the full length.

timer:Pause / timer:Resume

timer:Pause() timer:Resume()

Pause freezes the remaining time. Resume continues from there and errors if the timer is not paused.

timer:Stop

timer:Stop() -- aliases: Cancel, Kill

Ends a running or paused timer with the state Stopped, runs its callbacks and wakes waiting threads. Does nothing on a timer that already ended.

timer:Wait

timer:Wait(): (state: string, elapsed: number) -- alias: Yield

Yields until the timer finishes or stops and returns how it ended ("Finished" or "Stopped") and the elapsed seconds. On a timer that already ended, it returns at once.

timer:IncrementTime

timer:IncrementTime(delta: number)

Adds delta seconds (negative to shorten), whether the timer is running or paused.

Reading

timer:GetLength(): number timer:GetRemaining(): number timer:GetState(): string timer:IsRunning() / IsPaused() / IsFinished() / IsStopped() / IsDead() / IsDied()

Callbacks

timer:OnRunning(fn) timer:OnPaused(fn) timer:OnFinished(fn) timer:OnStopped(fn) timer:OnDead(fn) timer:OnDied(fn) timer.Callback = fn

Each On… adds a callback for that state, called as fn(state, seconds) in its own thread. OnDead and OnDied fire when the timer ends, finished or stopped. timer.Callback, if set, is called with the final state.

States

Timer.Enums -- also Timer:GetEnums() "Running" | "Paused" | "Finished" | "Stopped" | "Dead" | "Died"

After a timer ends, GetState reports "Dead"; Wait still tells you whether it finished or was stopped.
