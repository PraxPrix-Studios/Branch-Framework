Network types

The types you can write in a declaration's Data and Return. Each one decides both what the wire carries and what the server accepts from clients.

Numbers

TypeBytesRange
u8 / u16 / u321 / 2 / 4whole numbers from 0 up to 255 / 65,535 / 4,294,967,295
i8 / i16 / i321 / 2 / 4whole numbers, ±127 / ±32,767 / ±2,147,483,647
f162±65,504, about 3 significant digits
f324about 7 significant digits
f64 or number8a full Luau number

Ranges

Add a range in brackets. The server refuses values outside it.

"u8(0..100)"      -- 0 to 100
"i16(-500..)"     -- -500 or more
"f32(..1)"        -- at most 1

Stepped numbers

Add a step to a range, and the value travels as the index of the nearest step, in the smallest whole number that fits. It arrives rounded to your step.

"f32(0..1, 0.01)"        -- 101 steps: 1 byte instead of 4
"f32(-180..180, 0.5)"    -- 721 steps: 2 bytes instead of 4

Out-of-range values error at the caller when argument checks are on, and are clamped to the range when they are off. The server rejects any step index past the end of the range.

Sizes with Pack

On an event with Pack = true, these take only the bits their range needs instead of whole bytes:

TypeBits
boolean, an optional's "is it here" flag1
enum(A, B, C)enough for the count: 3 values → 2 bits
whole number with a range: u8(0..100), u32(0..5000)enough for the range: 0..100 → 7 bits, 0..5000 → 13
u8 / i8 / u16 / i168 / 8 / 16 / 16 (no change, but no padding either)
stepped numberenough for the steps: 101 steps → 7 bits
length of T[..n] or { [K]: V } with a maximumenough for n: [..64] → 7 bits
everything elsethe same bytes as without Pack

Containers

TypeMeaning
T[] or { T }An array of T.
T[..10], T[4], T[2..8]An array with a length limit or an exact length.
{ [K]: V }A map from K to V. Keys cannot be optional.
{ a: T, b: U }A struct with named fields. In a declaration you can also write it as a Lua table: Data = { a = "T", b = "U" }.
T?Optional: T or nil. The "present" flag is a single bit.
(T)Grouping, for example (u8[])?.

Clients can send arrays and maps up to Settings → Network → Max client array entries (16,384 by default). Lengths are checked against the packet's size before anything is allocated.

Names

Service, event and field names must be plain identifiers ([A-Za-z_][A-Za-z0-9_]*) and cannot be Luau keywords such as end or local. They become code, so the compiler refuses them instead of generating a module that cannot load.

Examples

Data = "u8"                                          -- one number
Data = { "Instance(Player)", "f32(0..100, 0.5)" }   -- two arguments
Data = { pos = "vector(f16)", state = "enum(Idle, Walk, Run)", target = "Instance(Model)?" }
Data = "{ [string]: u32 }"                           -- a map
Data = "{ id: u16, count: u8 }[..50]"                -- up to 50 structs
Return = "boolean"                                   -- a function's answer
