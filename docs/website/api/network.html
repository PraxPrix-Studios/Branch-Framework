api/network

Branch.Network

The code Branch Studio generates from your Service.Network declarations. Every event and function gets its own typed functions, so autocomplete shows the exact arguments.

At a glance

-- server: Branch.Network.Server.<Service>.<Event>
Net.Damage.Fire(player, 25)                   -- one player
Net.Damage.FireAll(25)                        -- everyone, sent once
Net.Damage.FireList({ a, b }, 25)             -- a list of players
Net.Damage.FireExcept(player, 25)             -- everyone but one
Net.Damage.FireNear(position, 100, 25)        -- players within 100 studs
Net.Mob.FireFrom(position, mob)               -- Lod events: rate by distance
Net.Unit.Forget(id)                           -- Delta + Key: drop an object's state
Net.Mob.Exact(id, true)                       -- Predict: no guessing for this object for now
Net.Hit.On(function(player, hit) end)         -- a client's event, already validated
Net.Buy.On(function(player, item) return true end) -- a function's one handler
Branch.Network.OnReject(function(player, reason, forged) end) -- refused packets, rate limits, guards
Branch.Network.Anticheat.OnFlag(function(player, check, detail) end) -- anticheat findings

-- client: Branch.Network.Client.<Service>.<Event>
Net.Hit.Fire({ Target = model })              -- to the server, batched per frame
Net.Damage.On(function(amount) end)           -- returns a function that disconnects
local pos = Net.Mob.At(id)                    -- Predict events: the guess for right now
local ok = Net.Buy.Invoke("sword")            -- yields for the answer; errors if it failed
Branch.Network.Anticheat.Check("speed", fn)   -- your own check, every 5 s (see Anticheat)
  • Batched per frame: everything you fire for a player in one frame leaves as one remote call, in order.
  • Server-side checks run before any listener sees a client's data; bad packets go to OnReject.
  • Declared, not called: the events come from Service.Network tables. Options such as Latest, Hz or Delta are in the Networking guide.

Every function in detail:

Branch.Network.Server.<Service>.<Event>   -- on the server
Branch.Network.Client.<Service>.<Event>   -- on a client
Branch.Network.OnReject                    -- on the server
Branch.Network.Anticheat                   -- both sides

The server half is generated into ServerScriptService.BranchNetworkServer, so players never download it; you always use it through Branch.Network.

In the signatures below, ...args stands for the arguments your Data declares: nothing, one value, a tuple, a struct table, or the struct's fields with Unpack. See Declare.

When it works:

  • Using Server on a client, or Client on the server, is an error.
  • Outside a running game (plugins, the command bar), every call does nothing.

Server → client events

Declared with From = "Server". Used from the server; received on clients.

Event.Fire server

Server.Service.Event.Fire(player: Player, ...args)

Sends to one player. Batched with that player's other events this frame.

Event.FireAll server

Server.Service.Event.FireAll(...args)

Sends to every player. The frame's broadcasts go out once, through FireAllClients, and each player still receives everything in order.

Event.FireList server

Server.Service.Event.FireList(players: { Player }, ...args)

Sends to each player in the list.

Event.FireExcept server

Server.Service.Event.FireExcept(except: Player, ...args)

Sends to every player but one.

Event.FireNear server

Server.Service.Event.FireNear(position: Vector3, radius: number, ...args)

Sends to every player whose Character.PrimaryPart is within radius studs of position. Players without a character are skipped.

Event.FireFrom server · Lod only

Server.Service.Event.FireFrom(position: Vector3, ...args)

Sends to every player, as often as the Lod ring their character is in allows: players near position often, far players rarely, players beyond the last ring (or without a character) not at all. Each player gets the newest value when their ring's turn comes. See Lod.

Event.Forget server · client · Delta only

Service.Event.Forget(key) -- Delta with Key Service.Event.Forget() -- Delta without Key

With a Key: drops the state kept for that key on this side and on every receiver (no listener is called), so the next send for that key is full. With Predict, it also turns Exact off for that key. A value for that key still waiting to be sent (Latest, Hz, Lod) is dropped too. Call it when the object is gone. Without a Key: the next send to every recipient is full.

Event.Exact server · Predict only

Server.Service.Event.Exact(key, on: boolean) -- Predict with Key Server.Service.Event.Exact(on: boolean) -- Predict without Key

Turns the guessing off (true) or back on (false) for one object, for every player. While it is off, every change is sent every frame, whatever Hz and Lod say, and At returns exactly what arrived: use it while precise movement matters, such as a fight. It takes effect with the object's next send, and the switch itself is smoothed over 0.1 seconds, so the object does not jump. See Predict.

Net.Mob.Exact(id, true)    -- the fight starts
Net.Mob.Exact(id, false)   -- the fight is over
Events with send-less options keep the same functions. With Latest, Hz or Lod, the newest values are written when the frame ships (with Hz and Lod, only on frames when their timer allows). With Delta, FireAll, FireList, FireExcept and FireNear write to each player separately. Threshold, Predict and Pack change only what travels, not how you call (Predict adds At on the client). See Send less.

Event.On client

Client.Service.Event.On(listener: (...args) -> ()): () -> ()

Listens for the event. Returns a function that disconnects the listener. Events that arrived before the first listener are queued and delivered to it.

Event.At client · Predict only

Client.Service.Event.At(key): ...values? -- Predict with Key Client.Service.Event.At(): ...values? -- Predict without Key

The guess for right now: one value for each predicted field, in the order they are declared, or nil before the first update for that key (and after Forget). With an Instance Key and StreamingEnabled, it is also nil until an update arrives while this client has the Instance. Each value is the last one that arrived plus its speed times the time since, kept inside the field's declared range; a correction is smoothed over 0.1 seconds. Call it every frame when you draw. See Predict.

RunService.RenderStepped:Connect(function()
	for id, part in parts do
		part.Position = Net.Mob.At(id) or part.Position
	end
end)

Client → server events

Declared with From = "Client". Used from a client; received on the server.

Event.Fire client

Client.Service.Event.Fire(...args)

Sends to the server, batched with the client's other events this frame.

Event.On server

Server.Service.Event.On(listener: (player: Player, ...args) -> ()): () -> ()

Listens for the event. player is who sent it, and every argument has already been validated against your declaration. Returns a function that disconnects the listener.

Functions

Declared with a Return. A client asks, the server answers.

Function.Invoke client · yields

Client.Service.Function.Invoke(...args): ...returns

Sends the request at once (it does not wait for the end of the frame) and yields for the answer. Raises an error if the server's handler errored, or if the request could not be queued on the server.

Function.On server

Server.Service.Function.On(handler: (player: Player, ...args) -> ...returns)

Sets the one handler for the function. Setting it again replaces the old one. Requests that arrived before the handler was set are answered once it is.

Rejected packets

Branch.Network.OnReject server

Branch.Network.OnReject(handler: (player: Player, reason: string, forged: boolean) -> ()): () -> ()

Called when a client sends a packet that fails validation: wrong sizes, out-of-range values, NaN, wrong Instance classes, forged lengths or oversized packets. The packet is dropped either way. Also called (at most once a second per player and event) when a client goes over an event's Rate (reason rate limit:) or breaks a guard (cooldown:, not alive:, too far:, not theirs:). forged is true for packets no Branch client can produce; those also count towards the automatic kick (Settings › Network › Kick after forged packets). Returns a function that removes the handler.

Branch.Network.OnReject(function(player, reason, forged)
	warn(`{player.Name}: {reason}{if forged then " (forged)" else ""}`)
end)

Anticheat

How it all fits together: Anticheat. Each finding is a check name and an optional detail; what happens is up to SetAction.

Anticheat.Check client

Branch.Network.Anticheat.Check(name: string, check: () -> any, every: number?): () -> ()

Adds a check that runs every every seconds (5 if left out, 1 or more) in a thread of its own. Returning a string (the detail) or true flags the player under name; the finding rides the next signed heartbeat. A name can be taken once. Returns a function that takes the check away and frees its name. Does nothing while the anticheat is off.

Anticheat.Report client

Branch.Network.Anticheat.Report(check: string, detail: string?)

Flags the player now, from your own client code; sent with a heartbeat on the next frame.

Anticheat.Flag server

Branch.Network.Anticheat.Flag(player: Player, check: string, detail: string?)

A finding of your server code: OnFlag, OnReject and the check's action, like any other. Works with the anticheat off too.

Anticheat.OnFlag server

Branch.Network.Anticheat.OnFlag(handler: (player: Player, check: string, detail: string?, score: number) -> ()): () -> ()

Called for every finding whose action is not "ignore", in Studio too, with the player's score after it. Returns a function that removes the handler.

Anticheat.Use server

Branch.Network.Anticheat.Use(name: "speed" | "teleport" | "fly" | "noclip", options: { [string]: number }? | false)

Turns on a ready-made movement check, with its options changed (speed: max 0 = WalkSpeed, tolerance 1.75; teleport: distance 100; fly: height 16, time 4); false turns it off. See Ready-made checks.

Anticheat.Pause server

Branch.Network.Anticheat.Pause(player: Player, seconds: number)

The ready-made checks leave the player alone for that long: your game moves them itself (a dash, a launch pad). Setting the character's CFrame from a script pauses them on its own.

Anticheat.Preset server

Branch.Network.Anticheat.Preset(name: "Basic" | "Advanced")

"Basic" (the default): each check acts on its own. "Advanced": checks only report, a score of 5 restricts, 10 kicks, 1 point a minute is forgotten. Calls to SetAction, SetLevel and SetDecay afterwards change it.

Anticheat.SetWeight server

Branch.Network.Anticheat.SetWeight(check: string, weight: number)

How much a finding of the check adds to the player's score (your checks: 1 by default).

Anticheat.SetLevel server

Branch.Network.Anticheat.SetLevel(at: number, action: "restrict" | "kick" | (player: Player, record: AnticheatRecord) -> () | nil)

When a player's score first reaches at, the action runs once. nil removes the level.

Anticheat.SetDecay server

Branch.Network.Anticheat.SetDecay(perMinute: number)

The score goes down by this many points a minute (0, the Basic default: never).

Anticheat.Restrict / IsRestricted server

Branch.Network.Anticheat.Restrict(player: Player, on: boolean?) · IsRestricted(player: Player): boolean

A restricted player's refused requests count as forged, and their rate limits refill at a quarter of the speed. Restrict(player, false) lifts it.

Anticheat.GetFlagged / GetRecord server

Branch.Network.Anticheat.GetFlagged(): { AnticheatRecord } · GetRecord(player: Player): AnticheatRecord?

The records of the players in the server with a finding (highest score first), or one player's. A record is a frozen copy: { player, score, restricted, checks = { [check] = { count, detail, at } }, history }, with the last 50 findings; at is os.time().

Anticheat.OnChanged server

Branch.Network.Anticheat.OnChanged(handler: (player: Player, record: AnticheatRecord?) -> ()): () -> ()

Called whenever a player's record changes; record is nil when it is gone (pardoned, or the player left). For live admin panels.

Anticheat.Pardon server

Branch.Network.Anticheat.Pardon(player: Player, check: string?)

Forgives one check (its findings and their score) or, without one, everything, restriction included.

Anticheat.ShareAcrossServers server

Branch.Network.Anticheat.ShareAcrossServers(on: boolean?)

Every server of the game shares its flagged players through MessagingService (changes at most every 3 s, messages under 1 KB). Call it on every server; false stops it and the others forget this server's players. See Across servers.

Anticheat.GetFlaggedGlobal / OnGlobalChanged server

Branch.Network.Anticheat.GetFlaggedGlobal(): { AnticheatGlobalEntry } · OnGlobalChanged(handler: (userId: number, entry: AnticheatGlobalEntry?) -> ()): () -> ()

The flagged players of this server and of every other server sharing, highest score first; an entry is a frozen { userId, name, score, restricted, checks = { [check] = count }, server, placeId, here }. The handler hears every change, with nil when a player is gone.

Anticheat.SetAction server

Branch.Network.Anticheat.SetAction(check: string, action: "kick" | "report" | "ignore", after: number?)

What a check does: "kick" (the default for every check but strict), "report" (handlers only) or "ignore". With after, "kick" kicks from a player's after-th finding of that check on; the ones before only report. Kicks never happen in Studio or with Kick after forged packets at 0.

Anticheat.SetKickMessage server

Branch.Network.Anticheat.SetKickMessage(message: string)

The message kicked players see.

Listener modes

CallHow listeners run
"Async" (default)Each call runs in a pooled thread, so a listener may yield freely.
"Sync"Listeners run inline, in the receive loop: the fastest option. A listener that yields does not corrupt later events, and one that errors is reported without dropping the rest of the packet.
