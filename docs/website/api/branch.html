api/branch

Branch

The module you require on both sides. It loads your segments and gives access to Branch.Data and Branch.Network.

local Branch = require(game.ReplicatedStorage.Packages.Branch)

Reading a key that does not exist on Branch is an error, so a typo such as Branch.Netwrok fails loudly. The utilities are ModuleScripts inside the package, not fields: see Utilities.

Branch.Version field

Branch.Version: string

The runtime version, for example "2.0.0".

Branch:Start method

Branch:Start(...roots: Instance, options: { SegmentRule: "Suffix" | "Folders" }?)

Finds the segments under every root, requires them, runs Init in dependency order, spawns every Start, then connects hooks. See Segments.

  • roots — one or more Instances to search.
  • options.SegmentRule — optional, last argument. Overrides the SegmentRule attribute that Branch Studio sets on the module. Without either, "Suffix".

Errors if called twice, if an argument is not an Instance (except a final options table), or if SegmentRule is not "Suffix" or "Folders". Arguments are checked before anything starts, so a bad call leaves Branch startable.

Branch:Start(script.Parent.Services)
Branch:Start(script.Parent.Services, script.Parent.Systems, { SegmentRule = "Folders" })

Branch:GetSegment method

Branch:GetSegment(name: string): Segment

Returns the table of the segment with that name. With Branch Studio the return value is typed per segment, so methods autocomplete.

Errors if there is no such segment. The error says so and names the current phase. Look segments up in Init or later, not at the top of a module.

Branch:LocateSegments method

Branch:LocateSegments(names: { string }): { [string]: Segment }

Looks up several segments at once and returns them keyed by name. Errors like GetSegment if any is missing.

local s = Branch:LocateSegments({ "PlayerService", "ShopService" })
s.ShopService:Open(player)

Branch:GetPhase method

Branch:GetPhase(): "Idle" | "Loading" | "Initializing" | "Started"

Where the start sequence is. "Idle" before Start; "Started" once every Start has been spawned and hooks are connected.

Branch:AwaitStart method · yields

Branch:AwaitStart()

Yields until the phase is "Started". Returns at once if it already is. Useful in scripts that are not segments.

Branch:GetReport method

Branch:GetReport(): { SegmentReport } type SegmentReport = { Name: string, Path: string, -- full name of the ModuleScript Status: "Loaded" | "Initialized" | "Failed" | "Started", InitMs: number, -- how long Init took }

One entry per loaded segment, in load order.

for _, segment in Branch:GetReport() do
	print(segment.Name, segment.Status, string.format("%.1f ms", segment.InitMs))
end

Branch.Network field · lazy

Branch.Network: { Server: …, Client: …, OnReject: … }

The compiled networking, loaded on first use. Errors if Branch Studio has not compiled it: turn on Compiled networking. See Branch.Network.

Branch.Data field · lazy

Branch.Data: { Server: …, Client: … }

Player data, loaded on first use. Only the side you are on is loaded, so ProfileStore never reaches a client's memory. Using the other side's table is an error. See Branch.Data.Server and Branch.Data.Client.

Segment fields

Branch reads these fields from each segment table. All are optional.

FieldTypeMeaning
Dependencies{ string }Segments whose Init must run first.
Init(self) -> ()Runs one segment at a time, in dependency order. May yield.
Start(self) -> ()Spawned after every Init.
PlayerAdded(self, Player) -> ()Current and future players, each in its own thread.
PlayerRemoving(self, Player) -> ()When a player leaves.
Heartbeat(self, dt: number) -> ()Every frame, after physics.
PreSimulation(self, dt: number) -> ()Every frame, before physics.
PreRender(self, dt: number) -> ()Every frame, before rendering. Client only.
NetworktableNetworking declarations, read by Branch Studio. See Networking.
