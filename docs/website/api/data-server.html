api/data-server

Branch.Data.Server

Player data on the server. Built on DataService and ProfileStore. For the ideas behind it, read Player data.

At a glance

local Data = Branch.Data.Server

Data.Start({ Template = {...}, Mock = true, Leaderstats = { "coins" }, Migrations = {...} }) -- once

Data.Get(player, "stats.kills")               -- nil until loaded, never errors
Data.Set(player, "coins", 5)                  -- checked against the template
Data.Increment(player, "coins")               -- +1 (or + delta), returns the new value
Data.Update(player, "best", function(old) return math.max(old, 10) end)
Data.Insert(player, "items", { id = 7 })      -- append (or pass an index)
Data.Remove(player, "items", 1)               -- returns what it removed

Data.Observe(player, "coins", function(new, old) end) -- now, and after every change
Data.OnLoaded(function(player, data) end)     -- every loaded player, then each new one
Data.Await(player)                            -- yields until loaded (nil if they leave)
Data.IsLoaded(player)                         -- without waiting

Data.Peek(userId)                             -- read an offline player's data (yields)
Data.Send(userId, "Gift", { "sword" })        -- delivered when they are online
Data.OnMessage("Gift", function(player, payload) end)
Data.Reset(player)                            -- wipe the profile and kick
Data.GetProfile(player)                       -- the raw ProfileStore profile
  • Template checks all the way down: a missing field or a wrong type is refused at your call, never in a save.
  • No NaN or infinity in any write: DataStores cannot store them.
  • Writes before loading error and tell you to use Await or OnLoaded; reads return nil.
  • Migrations run on a copy: if one fails, the saved data is untouched.
  • PlayerRemoving hooks can still write, and those writes are saved.

Every function in detail:

local Data = Branch.Data.Server

path is a dot path such as "stats.kills". With Branch Studio and a data template set, paths autocomplete.

Before a player's data loads:

  • Get returns nil;
  • Set, Update, Increment, Insert and Remove raise an error that tells you to wait with Await or OnLoaded.

Data.Start

Data.Start(config: Config) type Config = { Template: { [string]: any }, Store: string?, KeyPrefix: string?, Mock: boolean?, DontSave: boolean?, Migrations: { (data: any) -> () }?, Leaderstats: ({ string } | { [string]: string })?, }

Starts player data. Call it once, early (for example in a PlayerService:Init).

  • Template — the shape and starting values of every player's data. Every write is checked against it.
  • Store — the ProfileStore name. Default "PlayerData".
  • KeyPrefix — the DataStore key prefix. Default "PLAYER_".
  • Mock — keep data in memory only, never touching DataStores. Handy in Studio.
  • DontSave — load real data but never write it.
  • Migrations — Migrations[n] upgrades a profile from version n-1 to n. Run on a copy; see Migrations.
  • Leaderstats — a list of paths (the display name is the last part of the path) or a map of path → display name.

Errors if called twice or without a Template table.

Data.Get

Data.Get(player: Player, path: string?): any

The value at path, or the whole data table without a path. nil until the data loads. Never errors.

Data.Set

Data.Set(player: Player, path: string, value: any)

Writes value at path and syncs it to the player's client.

Errors if the value does not fit the template at that path (checked all the way down), or contains NaN or infinity.

Data.Update

Data.Update(player: Player, path: string, transform: (old: any) -> any): any

Calls transform with the current value and writes what it returns. Returns the new value. Checked like Set.

Data.Update(player, "stats.best", function(old) return math.max(old, score) end)

Data.Increment

Data.Increment(player: Player, path: string, delta: number?): number

Adds delta (default 1; can be negative) to a number and returns the new value.

Errors if the value is not a number, or the result is not finite.

Data.Insert

Data.Insert(player: Player, path: string, value: any, index: number?)

Inserts into the array at path: at the end, or at index. If the template's array holds an example element, value must match its shape. NaN and infinity are always refused.

Data.Remove

Data.Remove(player: Player, path: string, index: number): any

Removes the element at index from the array at path and returns it.

Data.Observe

Data.Observe(player: Player, path: string, callback: (new: any, old: any) -> ()): () -> ()

Calls callback(value, nil) as soon as the data is loaded, then callback(new, old) after every change, including when a parent table is replaced. Returns a function that stops observing.

Data.Await yields

Data.Await(player: Player): PlayerData?

Yields until the player's data is loaded and returns it. Returns nil if the player leaves first.

Data.IsLoaded

Data.IsLoaded(player: Player): boolean

Whether the player's data is loaded.

Data.OnLoaded

Data.OnLoaded(callback: (player: Player, data: PlayerData) -> ()): () -> ()

Calls callback for every player whose data is already loaded, then once for each player whose data loads later. Never twice for the same load. Returns a function that disconnects it.

Data.Peek yields

Data.Peek(userId: number): PlayerData?

Reads the saved data of any player, online or not, without taking their session lock. nil if they have no data.

Data.Reset

Data.Reset(player: Player)

Wipes the player's profile and kicks them, so their next join starts from the template.

Data.Send yields

Data.Send(userId: number, key: string, payload: { any }): boolean

Sends a message to a player's profile from any server. It is delivered when the player is online (now or on their next join), to the handler registered with OnMessage for that key. Returns whether it was sent.

Data.OnMessage

Data.OnMessage(key: string, handler: (player: Player, payload: { any }) -> boolean?)

Handles messages sent with Send under key. One handler per key: registering a second one for the same key is an error.

  • Handled. If the handler returns anything but false, the message is marked handled and removed.
  • Not handled. If it returns false, the message stays and is delivered again later.
  • Early messages. Messages that arrive before the handler exists wait for it.
Data.OnMessage("Gift", function(player, payload)
	Data.Insert(player, "items", payload[1])
	return true
end)

Data.GetProfile

Data.GetProfile(player: Player): Profile?

The underlying ProfileStore profile, or nil. An escape hatch: writes made through it skip Branch's checks and syncing.
