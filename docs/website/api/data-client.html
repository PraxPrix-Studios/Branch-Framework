api/data-client

Branch.Data.Client

A read-only mirror of the local player's data. It starts syncing as soon as it is required; there is nothing to start. Only the server writes.

local Data = Branch.Data.Client

If the server has not called Branch.Data.Server.Start, the client warns after 15 seconds.

Data.Get

Data.Get(path: string?): any

The value at path, or the whole data table without a path. nil until the data arrives.

Data.IsLoaded

Data.IsLoaded(): boolean

Whether the data has arrived.

Data.Await yields

Data.Await(): PlayerData

Yields until the data arrives and returns it.

Data.OnLoaded

Data.OnLoaded(callback: (data: PlayerData) -> ())

Calls callback once with the data: straight away if it has arrived, otherwise when it does.

Data.Observe

Data.Observe(path: string, callback: (new: any, old: any) -> ()): () -> ()

Calls callback(value, nil) once the data has arrived, then callback(new, old) after every change. Returns a function that stops observing.

local stop = Data.Observe("coins", function(coins)
	CoinLabel.Text = tostring(coins)
end)

Data.OnInserted

Data.OnInserted(path: string, callback: (index: number, value: any) -> ()): () -> ()

Calls callback whenever the server inserts into the array at path. Returns a function that disconnects it.

Data.OnRemoved

Data.OnRemoved(path: string, callback: (index: number, value: any) -> ()): () -> ()

Calls callback whenever the server removes from the array at path. Returns a function that disconnects it.
