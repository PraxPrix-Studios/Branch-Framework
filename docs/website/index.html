Build Roblox games on Branch

A game framework that stays out of your way. Split your game into services and controllers, keep player data safe, and send data between server and players faster than any other Roblox networking library we measured.

Get started Unique features API reference Benchmarks

Three parts that work together

  • SegmentsYour game is made of segments: modules named …Service on the server and …Controller on the client. Branch finds them, runs Init in dependency order, then Start, and gives you player and frame hooks. Segments guide
  • Branch.DataPlayer data on ProfileStore, with typed paths like "stats.kills". Every write is checked against your template, so a typo, a wrong type or a NaN can never reach a save. Player data guide
  • Branch.NetworkDeclare events on your services and get compiled buffer networking with batching, bit-packing and server-side validation. It beats Blink and NetRay in every benchmark except a function round trip, which ties. Networking guide

A taste

-- ServerScriptService/Services/CoinService
local Branch = require(game.ReplicatedStorage.Packages.Branch)

local CoinService = { Dependencies = { "PlayerService" } }

CoinService.Network = {
	Collect = { From = "Client", Data = "u16" },                -- coin id
	Coins   = { From = "Server", Data = "u32" },
}

function CoinService:Start()
	local Data = Branch.Data.Server
	local Net = Branch.Network.Server.CoinService

	Net.Collect.On(function(player, coinId)
		local coins = Data.Increment(player, "coins", 5)
		Net.Coins.Fire(player, coins)
	end)
end

return CoinService

The plugin compiles CoinService.Network into fast, typed networking code as you type. On the client, Branch.Network.Client.CoinService.Coins.On(...) receives the update.
