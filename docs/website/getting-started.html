Getting started

From an empty place to a running service and controller in five steps.

1. Install

Pick one way to get the runtime into ReplicatedStorage.Packages.Branch:

  • Branch Studio (easiest). Install the plugin, open the Branch toolbar, and press Install on the Overview page. The plugin writes the runtime for you and can update it later without losing your settings or generated files.
  • pesde. pesde add realllityyy/branch
  • Rojo. Build the repository's src/ folder (rojo build -o Branch.rbxm) and put the model in ReplicatedStorage.Packages.
Tip: even if you install with pesde or Rojo, use Branch Studio while you work. It compiles your networking and typed autocomplete as you type.

2. Make the folders

ServerScriptService
├─ Main                (Script)
└─ Services            (Folder)  ← server segments
StarterPlayer
└─ StarterPlayerScripts
   ├─ Main             (LocalScript)
   └─ Controllers      (Folder)  ← client segments

These are the default roots Branch Studio watches. You can change them in Settings → Paths.

3. Start Branch

Start Branch once on each side:

-- ServerScriptService/Main (Script)
local Branch = require(game.ReplicatedStorage.Packages.Branch)
Branch:Start(script.Parent.Services)
-- StarterPlayerScripts/Main (LocalScript)
local Branch = require(game.ReplicatedStorage.Packages.Branch)
Branch:Start(script.Parent:WaitForChild("Controllers"))

4. Your first service

A module whose name ends with Service is a server segment. Create Services/GreetService:

local GreetService = {}

function GreetService:Init()
	-- runs first, one segment at a time: set up state here
	self.greeted = 0
end

function GreetService:Start()
	-- runs after every segment's Init, in its own thread
	print("GreetService started")
end

function GreetService:PlayerAdded(player)
	-- runs for players already in the game and every new one
	self.greeted += 1
	print(`Hello, {player.Name}! ({self.greeted})`)
end

return GreetService

A module whose name ends with Controller is a client segment. Create Controllers/CameraController:

local CameraController = {}

function CameraController:Start()
	print("the client is ready")
end

function CameraController:PreRender(dt)
	-- every frame, before rendering (client only)
end

return CameraController

Press Play. Both segments start, and Branch:GetReport() lists them with their status and how long their Init took.

5. Add data and networking

Add a PlayerService that starts Branch.Data:

local Branch = require(game.ReplicatedStorage.Packages.Branch)

local PlayerService = {}

function PlayerService:Init()
	Branch.Data.Server.Start({
		Template = { coins = 0, stats = { kills = 0 } },
		Mock = game:GetService("RunService"):IsStudio(), -- no real saves while testing
		Leaderstats = { "coins" },
	})
end

return PlayerService

Then turn on Compiled networking on Branch Studio's Overview page, and declare events in a service's Network table. Here is GreetService again, with a wave players can send:

local Branch = require(game.ReplicatedStorage.Packages.Branch)

local GreetService = {}

GreetService.Network = {
	Wave = { From = "Client" },                    -- a client sends it, no data
	Waved = { From = "Server", Data = "string" },  -- the server sends it, one string
}

function GreetService:Start()
	local Net = Branch.Network.Server.GreetService
	Net.Wave.On(function(player)
		Net.Waved.FireAll(player.Name)
	end)
end

return GreetService

When you stop typing, Branch Studio compiles the events, so autocomplete knows them. On the client, in CameraController or any controller:

function CameraController:Start()
	local Net = Branch.Network.Client.GreetService
	Net.Waved.On(function(name)
		print(name, "waved")
	end)
	Net.Wave.Fire()
end

(Add local Branch = require(game.ReplicatedStorage.Packages.Branch) at the top of the controller too.)
