# Changelog

## Unreleased

Network code is generated by Branch Studio, so these arrive with the next plugin update; the runtime in `src/` is unchanged.

- **Latest** (`Latest = true`): several sends of an event to the same recipient in one frame send only the newest. With `Delta` and a `Key`, the newest value is kept per key (so many objects fired in one frame all arrive), and struct arguments are copied, so a caller may reuse its table.
- **Hz** (`Hz = 20`): the newest value goes out at most that many times a second; the last value is never lost.
- **Lod** (`Lod = { { 50, 30 }, { 200, 5 } }`, `Event.FireFrom(position, ...)`): each player gets the event at the rate of their distance ring, nothing beyond the last ring.
- **Threshold** (with `Delta`): numbers and vectors that moved less than the threshold count as unchanged; small moves add up.
- **Predict** (`Predict = { pos = 0.25 }`, with `Delta`, `Event.At(key)` on the client): a number or vector travels with its speed, the client guesses between updates, and an update goes out only when the guess is off by more than the number. Corrections are smoothed, teleports are shown at once, and an object that is no longer fired to a player stops where it was fired last. `Event.Exact(key, on)` turns the guessing off for one object while precise movement matters (a fight). The horde tutorial goes from 10.3 KB/s to 1.9 KB/s.
- **Pack** (`Pack = true`): small numbers, enums, booleans and bounded lengths travel as bits; a 200-item inventory takes about half the bytes.
- **Smaller types in one click:** Profile (Network page) + Finish (profiler window) lists the hints under Problems; a click rewrites the type.
- **Delta** (`Delta = true`, optional `Key`, `Event.Forget`): only the struct fields that changed since the last send travel; a changed boolean costs no bytes.
- **FireNear** (`Event.FireNear(position, radius, ...)`): sends only to players whose character is within the radius.
- **Rate limits** (`Rate = "10/s"`): extra client sends are dropped, functions answer "failed", and `OnReject` reports it.
- **Server half moved to ServerScriptService** (`BranchNetworkServer`): players no longer download the server's network code, and cannot read its checks. Existing places are moved over on the next compile.
- **Live network profiler** (Studio only): per-event traffic while you Play, with hints for smaller number types.
- **Docs website** in `docs/website`: guides, full API reference, benchmarks, unique features.

**Fixes (runtime)**

- `Data.Reset`, `Data.Send` and `Data.Peek` in `Mock` mode used the real DataStore (a Reset in a test could wipe a player's real save); they now use the Mock store. `Data.Peek` also ignored `KeyPrefix`.
- `Insert` / `Remove` on an array fired every observer of its elements with `old = nil`; now only elements that changed fire, with their old value.
- A `Timer` restarted from its own callback could no longer be stopped or paused.
- `Branch:Start({ folder })` (a table of roots) silently loaded nothing, and unknown options were ignored; both are now errors.
- The DataService remote ignores malformed client calls instead of erroring or flooding the output.
- The Data path cache no longer grows without limit with paths built at run time.
- `Util.Scythe`: a disposer that errors no longer stops the cleanup; every item is disposed and the error is raised once afterwards, as its notes describe.

## 2.0.0

A rewrite of Branch 1.

**Loader**

- `Branch:Start(roots..., options?)` replaces `StartSegments` / `StartSegmentsDeep`.
- Segment rule: `"Suffix"` (default: modules named `...Service` / `...Controller` at any depth) or `"Folders"`.
- Other loader changes:
  - `Dependencies` order `Init`;
  - frame hooks share one connection per hook type;
  - typed `GetSegment`, `GetReport`, `AwaitStart`;
  - duplicate names are errors;
  - warnings for dependencies that failed and for a `require` or `Init` that hangs.
- Utilities moved to `Branch.Util`: Scythe, ThreadReaper, Timer.

**Branch.Data** (on DataService + ProfileStore)

- Typed paths and template checks all the way down.
- NaN and infinity are refused; string keys that look like numbers (UserIds) work.
- Migrations run on a copy; leaderstats are bound to data paths.
- `Observe` fires when a parent table is replaced.
- Leave-time writes are saved.
- `Peek`, `Send`, `OnMessage`.

**Branch.Network**

- Compiled by Branch Studio from `Service.Network` declarations.
- Batching per player per frame, and one `FireAllClients` for FireAll.
- Run packing, bit-packed booleans, varint lengths, stepped numbers.
- Server validation; `OnReject`.
- Errors in listeners stay contained.

**Timer** (from Branch 1): fixed

- pause/resume;
- `IncrementTime` ordering;
- `Stop` with waiting threads;
- repeated callbacks;
- errors in callbacks.
