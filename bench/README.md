# Branch Network benchmarks

Branch vs NetRay (Compile 0.1.1) vs [Blink](https://github.com/1Axen/blink): the same events, the same data, the same machine. The results are on the [benchmarks page](https://praxprix-studios.github.io/Branch-Framework/website/benchmarks.html).

Everything here is the code that ran: each library's module, generated by that library's own tool from the same schema, and the harness around them.

## Run it in Lune

From the repository root, with [Lune](https://github.com/lune-org/lune) 0.10 (`rokit install` sets it up):

```sh
lune run bench/bench.luau                  # all 7 benchmarks: 300 frames, best of 5
lune run bench/bench.luau Cars 300 5       # only the ones whose name contains "Cars"
```

The Output lists every library for each benchmark, then how much faster or slower Branch is, then a summary. "X% faster" means the other library needs X% more time for the same work.

## Run it in Roblox Studio

Open `BranchBenchmark.rbxl` and press **Play** (not Run). Six benchmarks run one after another, about a minute in all, and the Output shows each result and a summary. To rebuild the place from these files: `lune run bench/engine/build.luau`.

## What is in here

| Path | What it is |
|---|---|
| `core.luau` | The Lune benchmark: mocked players and remotes, the workloads, the timing |
| `bench.luau` | Runs `core.luau` under Lune |
| `Bench.network.luau` | Branch's declaration of the benchmark events |
| `Definition.blink`, `netray/*.idl` | The same events for Blink and NetRay |
| `generated/branch/`, `generated/branch-unpack/` | Branch's code, generated by Branch Studio from `Bench.network.luau` (`branch-unpack`: the same with `Unpack = true` on the struct events) |
| `generated/Blink*.luau`, `generated/netray*/` | Blink's and NetRay's code, generated by their own CLIs |
| `engine/` | The Studio benchmark: `BenchServer` and `BenchClient`, the schemas, and `build.luau`, which builds the place |
| `generated/engine/` | Each library's code for the Studio benchmark |
| `BranchBenchmark.rbxl` | The built Studio place |

## Keeping it fair

- **Same work:** every library gets the same schema, the same data and the same mocked wire (Lune), or the same place (Studio).
- **Same instrumentation:** in the Studio place, the same counters are added to all three modules: remote calls, bytes, and the time of the frame flush.
- **Branch's Studio-only profiler is off,** as it is in a live game (`PROFILE = false` at the top of Branch's modules).
- **Branch validates what the server receives, and its numbers include that.** NetRay does not validate by default; the Lune benchmark also runs NetRay with `Validate=Full`.
- **The code is not rewritten afterwards.** Only Branch's code comes from Branch Studio, which is free but closed source; the generated modules are here in full.
